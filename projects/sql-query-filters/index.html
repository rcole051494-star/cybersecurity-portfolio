Apply Filters
to SQL Queries

Using SQL filters to investigate security events and identify systems or employees that require action.

SQLMariaDBSecurity investigationData filtering

Scenario and purpose

Finding useful security information in large datasets.

Security analysts use SQL to isolate events that may indicate malicious activity and to identify systems that need updates. In this activity, I filtered login records by time, date, success status, and country, then filtered employee records by department to support security-related tasks.

Completed queries

Six filters applied in MariaDB

After-hours failed logins

SELECT *
FROM log_in_attempts
WHERE login_time > '18:00'
  AND success = 0;

Combined a time condition and Boolean value with AND.

Logins on two dates

SELECT *
FROM log_in_attempts
WHERE login_date = '2022-05-09'
   OR login_date = '2022-05-08';

Used OR to retrieve activity from either specified date.

Logins outside Mexico

SELECT *
FROM log_in_attempts
WHERE NOT country LIKE 'MEX%';

Combined NOT, LIKE, and the % wildcard.

Marketing employees

SELECT *
FROM employees
WHERE department = 'Marketing';

Retrieved records that exactly matched one department.

Finance or Sales employees

SELECT *
FROM employees
WHERE department = 'Finance'
   OR department = 'Sales';

Used OR to return either of two department values.

Employees outside IT

SELECT *
FROM employees
WHERE NOT department =
  'Information Technology';

Excluded the Information Technology department with NOT.

Skills demonstrated

Translating investigation questions into precise filters.
