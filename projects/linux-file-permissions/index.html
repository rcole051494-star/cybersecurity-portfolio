Overview

Using Linux commands to review and adjust access.

Using Linux commands, I navigated to a specific directory, confirmed the current permissions on a set of files, and changed them to reflect policy requirements.

What I did

Key steps

  • InspectUsed ls -la to list all items, including hidden files, in long format so permissions were visible.
  • ReadInterpreted the permissions string: user, group, and other sets, each with read, write, and execute. A leading d marks a directory.
  • ModifyUsed chmod to add or remove permissions for files, a hidden file (.project_x.txt), and directories.

Summary

Outcome

I used chmod to modify permissions on files and directories for the user, group, and other sets, adding and removing read, write, and execute permissions, and verified each change with ls -la.
