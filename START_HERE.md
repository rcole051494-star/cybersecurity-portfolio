# Make This Portfolio Yours

The main portfolio is `README.md`. It includes your preferred name, Reagan Cole, your enrollment in Merit America's cybersecurity program, and your completion of the first three Google Cybersecurity courses on Coursera. The full professional certificate is marked in progress.

## Personalize the Introduction

Expand the About Me section with your previous experience, why cybersecurity interests you, and the kind of work you want to pursue. Include a LinkedIn profile or professional contact method only if you want it public. You can also add your individual course certificate links and completion dates.

Compare the portfolio with your program's assignment requirements before submitting it.

## Add Your First Project

1. Choose an assignment or lab you completed and are allowed to share.
2. Copy `templates/project-writeup.md` into a folder such as `projects/security-audit/`, naming the copy `README.md`.
3. Replace the prompts with your own work. Put supporting images in an `images` folder beside that project write-up.
4. Replace the introductory text in the main Project Showcase section with a link and a short description. For example, once the file exists:

   ```markdown
   ### Security Audit
   [Read the project](projects/security-audit/README.md)

   A review of [your actual scenario], documenting [your actual findings].
   ```

Use only project evidence you may share, with passwords, tokens, and personal information removed.

## Publish on GitHub

Create a repository in your GitHub account, then upload this portfolio's files and folders. A repository named `cybersecurity-portfolio` is a straightforward choice. Choose public visibility if your assignment requires a publicly accessible link. Share the repository link after checking that the README and project links display correctly.

GitHub's official instructions:

- [Create a repository](https://docs.github.com/en/repositories/creating-and-managing-repositories/creating-a-new-repository)
- [Upload files](https://docs.github.com/en/repositories/working-with-files/managing-files/adding-a-file-to-a-repository)
