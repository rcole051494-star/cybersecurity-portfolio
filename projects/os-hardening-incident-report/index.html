Overview

Analyzing a website compromise and recommending a practical defense.

In this course scenario, a threat actor obtained administrative access to a web server through a brute-force attack, modified the website, and redirected visitors to a malicious domain. I reviewed the supplied network information and documented the incident in a structured report.

Key findings

What the investigation established

  • ProtocolsHTTP delivered the malicious file, DNS resolved the domain names, and IPv4 carried packets between devices.
  • AttackThe attacker gained access to the administrative account through a brute-force attack against an unchanged default password.
  • Hardening methodLimiting failed login attempts and locking the account would restrict repeated password guesses.

Skills demonstrated

From network evidence to a clear incident record

This activity demonstrates my ability to distinguish the roles of HTTP, DNS, and IPv4; summarize an attack vector and its impact; document investigation steps; and connect a security-hardening method to the weakness it addresses.
